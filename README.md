## Featured Projects

### [HireScope](https://github.com/dayunbibi/hirescope) · [Live demo](https://hirescope-xi.vercel.app)
Toronto developer job market analytics. A Python scraper collects GTA job postings from Greenhouse, Lever, RemoteOK and Jobicy every day (GitHub Actions), a FastAPI + PostgreSQL API serves them, and a Next.js frontend shows jobs, companies and hiring stats on a transit-map style UI.
*Next.js · TypeScript · Python · FastAPI · PostgreSQL*

### [FocusPlan](https://github.com/dayunbibi/focusplan) · [Live demo](https://focusplan-silk.vercel.app)
Mobile-first student planner for classes, tasks, assignments, exams and study sessions. Session-based auth, Server Actions with Prisma, and a one-click demo account (`Try demo account` on the login page).
*Next.js · TypeScript · Prisma · PostgreSQL*

### [BoardMeet](https://github.com/dayunbibi/boardmeet) · [Live demo](https://boardmeet-v2.vercel.app)
Meetup coordination app for a recurring board game club: attendance polling, game suggestions and announcements. In active use by the club.
*Next.js · TypeScript · Supabase*

### [BudgetScope](https://github.com/dayunbibi/BudgetScope) · [Live demo](https://budget-scope.vercel.app)
Budgeting app built to practice relational schema design: accounts, categories and atomic account-to-account transfers written in raw SQL (no ORM).
*Next.js · TypeScript · PostgreSQL*
